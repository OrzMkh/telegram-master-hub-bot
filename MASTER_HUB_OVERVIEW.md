## 📌 Ключевые Модули и Возможности

### 📋 1. Управление Задачами & Контроль SLA (FlitGo Tasks)
- **Автоматический сбор:** Бот распознает задачи, поставленные руководителем в рабочей группе Telegram, и моментально заносит их в базу данных и Google Таблицы.
- **Контроль дедлайнов (SLA):** Автоматический подсчёт времени выполнения с цветовой индикацией срочности (🟢 Обычный, 🟡 Средний, 🔴 Срочный).
- **Система Оценки Качества (1–5 ⭐️):**
  - Руководитель завершает задачу в Web App и выставляет оценку (1–5 звёзд) с комментарием.
  - В рабочую группу мгновенно отправляется интерактивная карточка с результатом.
- **Справедливое оспаривание:** Если исполнитель не согласен с оценкой (< 5 звёзд), он может нажать кнопку **«⚖️ Оспорить оценку»** прямо в Telegram и указать аргументы для пересмотра.

### 🛵 2. Мониторинг Парка & Байки (Bike Reports)
- **Учёт статуса техники:** Детализация по городам (Ташкент, Самарканд, Бухара и др.) — сколько байков на линии, сколько на ремонте, сколько готовы к выезду.
- **Двусторонняя синхронизация:** Прямая интеграция с Google Sheets и локальной базой данных.
- **Оперативный дашборд:** Графики динамики поломок, готовности аккумуляторов и эффективности технических бригад.

### 💰 3. Расчёт Заработной Платы и Налогов (ТК РУз)
- **Автоматизация ФОТ:** Расчёт аванса, основной части зарплаты, налоговых удержаний и пенсионных взносов по стандартам Трудового кодекса Республики Узбекистан.
- **Учёт KPI и дисциплины:** Интеграция оценок за задачи, бонусов и штрафов в итоговый расчёт сотрудника.
- **Экспорт отчётности:** Формирование и выгрузка готовых сводных таблиц в формате Microsoft Excel (`.xlsx`) в один клик.

### 👥 4. Управление Доступами и Безопасностью
- **Единый шлюз авторизации:** Управление ролями сотрудников (Администратор, Партнёр, Техник, Менеджер).
- **Мгновенная блокировка:** Возможность в один клик отозвать доступ уволенного сотрудника во всех ботах сразу.
- **Защищённый межсервисный API:** Обмен данными между Master Hub и дочерними ботами защищён криптографическим токеном `INTERNAL_API_SECRET`.

## ⚙️ Конфигурация и Переменные Окружения

| Переменная | Назначение |
| :--- | :--- |
| `BOT_TOKEN` | Токен основного бота Master Hub (@TopMgsBot). |
| `TASK_BOT_TOKEN` | Токен Task-бота для отправки уведомлений и карточек в группу. |
| `TASK_CHAT_ID` | ID рабочей Telegram-группы для получения отчётов и задач. |
| `INTERNAL_API_SECRET` | Секретный ключ для авторизации запросов между серверами. |
| `GOOGLE_CREDENTIALS_JSON` | Ключ сервисного аккаунта Google Cloud для работы с Таблицами. |
| `MASTER_APP_PASSWORD` | Пароль доступа к административной панели Web App. |

## 🔒 Стандарты Безопасности
1. **Изоляция секретов:** Ни один токен или пароль не хранится в открытом коде на GitHub.
2. **Защита от фишинга:** Все скомпрометированные токены отозваны, управление ведётся через изолированные переменные Render.
3. **Отказоустойчивость:** Мгновенный отклик интерфейса за счёт асинхронной обработки и фоновой синхронизации с Google Cloud.
